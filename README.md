# Gráfico de Andamentos

Ferramenta composicional para explorar **relações entre andamentos**: a
partir de um andamento principal e de proporções (andamentos secundários),
gera um gráfico com os andamentos relacionados, permite marcá-los e ouvi-los
com um metrônomo duplo.

**Criado por Rogério Tavares Constante.**

### ▶ [Abrir no navegador](https://rogerioconstante.github.io/grafico-de-andamentos/)

Funciona em qualquer navegador moderno, sem instalação; também pode ser
usado baixando o repositório (**Code ▸ Download ZIP**) e abrindo o
`index.html`.

## Funcionalidades

- **Andamento principal**, diferença máxima e até quatro **proporções**
  secundárias (ex.: 3:2, 5:4).
- **Gráfico** das relações, com ordenação e duas cores de **marcação**.
- **Metrônomo** para dois andamentos simultâneos (cowbell grave e agudo), com
  indicação em MM e milissegundos.
- **Presets**: salvar e abrir configurações em arquivo.
